# Changelog

All notable user-facing changes are documented here.

## 0.1.0a2 — Unreleased

### Changed

- Remove unused report-label and text-line protocol code from the alpha package.

## 0.1.0a1 — 2026-08-31

### Added

- Offline PySide6 editor for PAGE 2013 XML transcription, polygons, and baselines.
- Reversible, reviewable Arabic ground-truth correction with local audit reports.
- Cross-platform automated checks and build artifacts for the first alpha.

### Changed

- Saving now reports recoverable backup and durability problems clearly.
- Vertex handles remain editable when overlapping another line region.
- The editor presents its current mode persistently and improves keyboard focus and
  accessibility labels.

### Known alpha limitations

- PAGE XML support is limited to the 2013-07-15 namespace.
- Releases provide Python source and wheel artifacts, not signed desktop installers.
